# 2.0.0 — 2026-06-27

A from-scratch rebuild on [`@cyanheads/mcp-ts-core`](https://www.npmjs.com/package/@cyanheads/mcp-ts-core), superseding the legacy 1.0.x line. The five always-on tools need zero configuration; the two host-probing tools stay absent from `tools/list` until explicitly enabled, so a hosted instance carries no SSRF or info-disclosure surface.

## Added

- **`toolkit_hash_value`** — generate a cryptographic digest (sha256/sha512/sha1/md5) or constant-time-compare a value against an expected digest via `timingSafeEqual`. Input read as utf8/hex/base64; md5/sha1 are flagged checksum/compat only, never for security.
- **`toolkit_generate_id`** — mint CSPRNG identifiers (UUIDv4, UUIDv7, ULID), single or batch up to 1000. Non-idempotent by design (`readOnlyHint: false`).
- **`toolkit_generate_qr`** — encode text or a URL into a QR code as SVG markup, base64 PNG (with `mimeType` and `byteLength`), or a terminal-renderable string; configurable error-correction, margin, and scale, with the symbol `version` (1–40) returned.
- **`toolkit_encode_value`** — encode or decode across base64, base64url, hex, and URL percent-encoding, in either direction; malformed decode input is a typed recoverable error, not silent best-effort.
- **`toolkit_geolocate_ip`** — resolve a public IP or hostname to country, region, city, coordinates, ASN, organization, and timezone. The server calls the provider (keyless ip-api by default), never the target, so the lookup is SSRF-free; absent upstream fields are reported as unknown, never invented.
- **`toolkit_check_network`** (gated by `TOOLKIT_ENABLE_NET_DIAGNOSTICS`) — read-only ping, traceroute, TCP connectivity, or host egress-IP detection. A second gate (`TOOLKIT_ALLOW_PRIVATE_NETWORK`) governs private/reserved/loopback/link-local targets, blocking the cloud-metadata endpoint by default. Node-only.
- **`toolkit_check_system`** (gated by `TOOLKIT_ENABLE_SYSTEM_INFO`) — report one host facet per call: OS, CPU, memory, load average, or non-internal network interfaces. Node-only.
- **`GeoService`** — DNS resolution, provider call with retry/backoff, sparse-payload normalization, and an in-memory TTL cache keyed by resolved IP; the private-range guard runs after resolution so a hostname cannot smuggle a lookup to an internal IP. Provider failures surface a sanitized `serviceUnavailable` — the upstream URL, HTTP status, response body, and requestId stay in server-side logs and never reach the client.
- **`NetDiagService`** with a shared `NetworkTargetSchema` validator and `isPrivateOrReservedIp` classifier (IPv4, IPv6, IPv4-mapped IPv6, and CGNAT ranges) — the single request-time chokepoint every target-bearing network mode passes through.
- Fail-closed tool registration and a two-tier network gate; typed error contracts with recovery hints on every fallible tool.
- STDIO and Streamable HTTP transports; Docker image and `.mcpb` bundle for one-click Claude Desktop install.

## Changed

- **Security posture inverted.** The legacy line exposed network and system diagnostics unconditionally; they are now off by default behind enable-gates, registered only when their flag is set. Deployments that relied on those tools must set `TOOLKIT_ENABLE_NET_DIAGNOSTICS` and/or `TOOLKIT_ENABLE_SYSTEM_INFO` to restore them.
