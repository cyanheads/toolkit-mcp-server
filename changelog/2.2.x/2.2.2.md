# 2.2.2 — 2026-08-22

## Fixed

- **Dockerfile build stage now runs on `$BUILDPLATFORM`**, cross-compiling instead of emulating for the multi-arch GHCR build. Bun `1.4.0` aborts under QEMU emulation, which is why no `2.2.1` image reached GHCR; published image contents are unchanged, since only `dist/` crosses into the production stage, which installs its own dependencies natively per target architecture.
