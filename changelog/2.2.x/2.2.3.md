# 2.2.3 — 2026-09-13

## Changed

- **Declared domain rejections on `toolkit_encode_value`, `toolkit_generate_qr`, and `toolkit_hash_value` return `ValidationError` instead of `InvalidParams`** — framework `0.12.7` made `InvalidParams` (-32602) the envelope for argument rejections the handler never sees. Every reason string and recovery hint is unchanged; a client branching on the numeric code must update.
- **`toolkit_encode_value` renders its result through `markdown().codeBlock()`** — the framework builder has sized its fence past the longest backtick run in the payload since `0.12.5`, which is what the tool's local `fence()` helper existed to do.
- **The framework skill tree moved from `skills/` to `framework-skills/`** (`0.13.0`) — plugin hosts auto-load a root `skills/`, so a server shipping `.claude-plugin/` handed its development skills to every agent that installed it. `devcheck`, `lint:packaging`, `.mcpbignore`, and `.github/CONTRIBUTING.md` follow the path.
- **Both plugin manifests declare the seven `TOOLKIT_*` options** — `.claude-plugin/plugin.json` collects them through `userConfig` and `${user_config.<key>}`, `.codex-plugin/mcp.json` forwards them through `env_vars`. An unanswered option falls to its schema default, since `0.13.0` reads an empty string and a whole-value `${…}` placeholder as unset.
- **Bun engines floor raised to `>=1.4.0`**, matching the framework's own floor since `0.12.9`.
- **`bun run audit:fix` runs `bun audit fix`** (`0.13.0`) — it previously ran a read-only audit and changed nothing.
- **`manifest.json`, both plugin manifests, and the Docker OCI label carry the `package.json` description.**
- **Issue forms accept a blank issue and link the private security advisory form**; new reports auto-assign.

## Removed

- **`MCP_RESPONSE_VERBOSITY` and the `OAUTH_PROXY_*` variables are no longer recognized** (`0.12.8`) — the framework validated both at startup and read neither.

## Fixed

- **An upstream `500` from the geolocation provider retries** (`0.12.4`) — no HTTP status maps to `InternalError` now, so a provider blip reaches the retry path as `ServiceUnavailable`. A `501` carries `data.retryable: false` and still fails on the first attempt with the sanitized message.
- **A caller that disconnects mid-call classifies as `RequestCancelled` (-32011)** (`0.12.4`) rather than `InternalError`, and the HTTP transport answers `499`.
- **A trailing slash on `MCP_PUBLIC_URL` no longer doubles** in the landing page and `/.well-known/mcp.json` links (`0.12.8`), and the landing page's `curl` snippet sends a handshake `initialize` accepts (`0.12.9`).
- **`notifications/cancelled` closes that request's SSE stream immediately** (`0.12.9`) instead of holding it open to keep-alive.
